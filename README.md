# Quick Pause

Freeze or slow the game with Escape or a hotkey, without opening the pause menu.

Part of the [Speedrun modpack](https://thunderstore.io/c/hades-ii/p/adamantSpeedrun/Speedrun_Modpack/).

## What It Does

Quick Pause is a practice and routing tool. Instead of the pause menu, it applies the game's own simulation-speed slowdown, so the world stops (or slows) while the screen stays clear.

- **Escape pauses without the menu:** during plain gameplay, Escape toggles the freeze instead of opening the pause menu. It does nothing over boon screens, the codex, the trait tray or while you are dead, where Escape keeps its normal behaviour. Hold **Shift** and press Escape to open the real pause menu.
- **Pause hotkey:** an optional key (F5 to F12) that toggles the freeze. It is read every frame while the Hell2Modding overlay is closed.
- **Speed while paused:** a percentage of normal game speed. 0 is a full freeze.
- **Block actions while paused:** stops attacks and dashes from queueing up. Leave it off if Escape stops unpausing.
- **PAUSED indicator:** a line in the lower centre of the screen while paused.

The freeze is always released when the module is disabled, when a new run starts and when you enter a room.

## Notes

- This is not the game's pause menu. Timers that run on real time, such as a real-time timer, keep running while you are frozen.
- The module is off by default. Enable it in the Speedrun modpack window.

## Installation

Install via r2modman.

This module is usually installed as part of the full [Speedrun modpack](https://thunderstore.io/c/hades-ii/p/adamantSpeedrun/Speedrun_Modpack/), where it appears in the shared Speedrun UI with the other speedrun-focused modules.
